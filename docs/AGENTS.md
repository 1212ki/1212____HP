# 1212HP Docs Contributor Guide

`docs/` を変更する前に `DOCS_RULES.md` を読み、そこにある canonical map と設計先行 gate に従ってください。

- `specs/current/` と `product/` は current truth の層です。
- `plans/`、active AI-DLC workspace、accepted history、bootstrap audit、decision history は別の責務です。
- closed trace や legacy document を current canonical の代わりに使いません。
- current truth を変える場合は formal AI-DLC cycle と必要な approval を先に通します。
