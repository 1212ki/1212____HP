# 1212HP Product Guidance

`docs/product/` は、個別機能を横断して実装判断に使う current product guidance の受け入れ先です。

この directory に置いただけでは canonical になりません。dedicated formal AI-DLC cycle で source、alternatives、trade-offs、affected current specifications、必要な human approval を記録し、承認された内容だけを current guidance として追加します。

## Current Guidance

現在、`docs/specs/current/` と `DESIGN_RULES.md` から独立した product guidance は承認されていません。

会話、個人メモ、bootstrap audit、active/closed cycle trace は proposal の source にはできますが、自動的にはここへ昇格しません。
