## 差として扱うがマスタ修正を要しない点

- ヘッダー・ナビ・フッター・Menuの寸法は#44の実装のまま。5画面とも変えない。
- Fieldの入力欄の見本値、LiveCardの文字（日付・会場・タイトル）、Ticket完了の作品名は構造の見本で、本番の掲載内容として使わない。

- 色は`color/*`変数が`DESIGN_RULES.md`・tokensと一致している。余白・間隔・角丸は数値の直書きで、実装は`--space-*`・`--radius-*`に当てはめる（許可スケールに無い値は無い）。
